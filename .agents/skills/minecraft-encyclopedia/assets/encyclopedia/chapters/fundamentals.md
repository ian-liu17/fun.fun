# MINE!!! — Minecraft Illustrated Encyclopedia

Java 1.21.4. The MINE!!! adventure uses custom recipes; this guide documents Minecraft registry facts. Unknown fields are labeled.

## 01. How blocks work

Start with the world beneath your feet.

Hardness measures breaking time; blast resistance measures resistance to explosions. They are different properties.

A placed block is not always obtainable as an inventory item. Air, fluids and technical states appear in the registry too.

Survival emphasizes gathering and progression; Creative provides building materials and flight. Adventure restricts interaction through map rules. Spectator is for observing the world. This field guide is distinct from the custom MINE!!! adventure rules.
